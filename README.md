# L1 Desktop Support Troubleshooting Toolkit

## Project Overview
A Python-based toolkit developed to practise basic Level 1 IT support tasks on Windows computers.

## Technologies Used
- Python 3
- Windows Command Prompt
- CSV file handling
- Visual Studio Code

## Features
1. System Information
2. Network Configuration
3. Internet Connectivity Test
4. DNS Lookup
5. Disk Space Check
6. Troubleshooting Report Generation
7. Troubleshooting Guide
8. Create Support Ticket
9. View Support Tickets
10. Update Ticket Status

## How to Run
1. Install Python 3.
2. Download the project files.
3. Open the project folder in VS Code.
4. Open the terminal and run:

   `python desktop_support_toolkit.py`

## Learning Outcomes
- Practised basic Windows troubleshooting.
- Learned network configuration and connectivity checks.
- Practised DNS troubleshooting.
- Implemented support ticket creation and status tracking.
- Generated troubleshooting reports.

## Project Purpose
This project demonstrates foundational skills relevant to an entry-level L1 Desktop Support role.

## Limitations
This is a learning project. It performs basic diagnostic checks and does not automatically repair computer or network problems.
