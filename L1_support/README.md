# L1 Desktop Support Troubleshooting Toolkit

## Project Overview
This is a Python-based project designed to simulate basic Level 1 IT support activities on Windows computers.

## Technologies Used
- Python 3
- Windows Command Prompt
- CSV file handling
- Visual Studio Code

## Features
1. System Information
2. Network Configuration
3. Internet Connectivity Test
4. DNS Lookup
5. Disk Space Check
6. Troubleshooting Report Generation
7. Troubleshooting Guide
8. Create Support Ticket
9. View Support Tickets
10. Update Ticket Status

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the command:

   `python desktop_support_toolkit.py`

## Learning Outcomes
- Learned basic Windows troubleshooting.
- Practised IP configuration and connectivity checks.
- Learned basic DNS troubleshooting.
- Implemented ticket creation and status tracking.
- Generated troubleshooting reports.

## Project Purpose
This project was created for learning and practising basic L1 Desktop Support skills.

## Limitations
This is a beginner learning project. It performs basic diagnostic checks and does not automatically repair computer or network problems.
